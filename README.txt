Интерактивное резюме Яны Шпаковой

Публикация через GitHub Pages:
1. Создайте/откройте аккаунт GitHub.
2. Создайте публичный репозиторий, например yana-resume.
3. Загрузите index.html (и photo.jpg, если добавили фото).
4. В Settings → Pages выберите Deploy from a branch, ветку main и папку /(root), сохраните.
5. После публикации GitHub покажет публичную ссылку вида https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/yana-resume/.
6. Откройте ссылку и сделайте скриншоты всей страницы или сохраните страницу в PDF.

Перед публикацией замените контактные заполнители, добавьте фото и проверьте формулировки проектов.
